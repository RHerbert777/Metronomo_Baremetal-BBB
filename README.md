# 🎛️ Metrônomo Baremetal na BeagleBone Black

## 📖 Descrição
Projeto desenvolvido na disciplina de TPSE1, onde foi construído um metrônomo operando inteiramente em *baremetal* utilizando o módulo de PWM (EHRPWM) da placa. O sistema explora o acesso direto aos registradores de hardware, permitindo não apenas a marcação precisa de tempo em diferentes BPMs (metrônomo simples), mas também a manipulação de frequências para a execução de melodias complexas.
